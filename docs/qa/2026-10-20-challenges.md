# 社区挑战闭环验证

## 范围

挑战生命周期、参与状态、挑战投稿约束、管理员分页目录、按挑战筛选待审投稿和后台操作界面。该验证只运行在开发环境，不代表线上服务或微信真机验收。

## 自动化与接口

`pnpm --filter @lumi/api test:challenges` 使用本机 NestJS、PostgreSQL、Redis 与 SeaweedFS，执行 20 次带状态断言的真实 HTTP 请求。覆盖管理员 RBAC、DTO 状态过滤、草稿/发布/关闭、实际签名上传和素材拥有权、未参加时拒绝投稿、参加后投稿、挑战维度待审核队列、帖子审核审计/通知，以及投稿后禁止退出。

参与变更和挑战投稿校验在同一个挑战行锁下串行化，避免退出与投稿并发产生违反产品约束的状态。重复参与保持首次参与时间，减少非幂等状态抖动。

## 后台浏览器

Playwright 本机浏览器实际登录后台，检查挑战空态、创建草稿、草稿列表、发布确认与状态刷新。临时浏览器账号和挑战已从本机数据库清理。由于 4400 端口已被占用，后台运行于 4401；本次为浏览器真实操作，并非截图静态稿。
