# 图片审核联调记录

日期：2026-10-20

## 已验证

- 管理员/审核员可读取图片审核队列，普通用户返回 403。
- 队列根据关联关系区分人物资料、衣物素材和生成结果，支持审核状态与用途筛选。
- 图片审核状态独立于上传状态；本地私有预览仍使用原有媒体读取边界。
- 审核通过/拒绝要求更新时间并发校验，拒绝原因和操作者写入审计。
- 审核历史支持游标分页；旧版本审核返回 409，避免覆盖其他审核员决定。
- 被拒绝的输入图片不能创建新的试穿任务。

## 证据

`LUMI_API_URL=http://127.0.0.1:14330/api/v1 pnpm --filter @lumi/api test:media-moderation`：15 次真实 loopback HTTP 请求通过。

测试仅使用唯一的本地 PostgreSQL fixture 用户和素材，结束时清理审核记录、素材和用户；未调用外部模型或对象存储。

## 当前边界

当前审核是人工队列，尚未接入内容安全模型、批量审核、自动处置或生产审核值守；真实 S3/微信图片链路仍需独立环境验收。
