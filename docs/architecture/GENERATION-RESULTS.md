# 生成结果生命周期

本阶段对应 G08：实现结果确认、云端保存/取消保存、删除、短期分享、相册保存及确认后带入发布编辑。它不代表真实模型、生产域名配置或微信真机验收完成。

## 不变量

- 只有任务拥有者可以操作成功任务的可用结果；他人的任务/结果统一返回 404。所有写操作在事务中锁定任务，确认同任务结果时最多有一个 selectedAt。
- 确认和云端保存为显式幂等状态写入，重复请求保留首次时间；云端保存不是下载到手机相册，也不复制成一件衣物。保存前必须确认该结果。
- 删除为幂等软删除，清除确认/保存状态，任务和额度账本保留，成功消费不退款。任务查询不再返回已删除或不可用资产。
- 删除结果与资产标记、S3 清理任务在同一事务提交；失败不能只删一半。沿用私有存储清理 worker，不在数据库事务中调用外部存储。
- 帖子创建与图片删除锁定同一媒体行。任何未删除的帖子（包括待审/拒绝）引用图片时拒绝删除，提示先删除帖子。通用媒体删除接口不能绕过活跃结果保护。
- 生成结果用于发帖时必须已确认，服务端强制 AI 标记；发布仍进入审核，不更改图片的私有存储权限。local-svg 仅开发验证，不支持或冒充真机下载能力。
- 分享使用 32 字节随机 token 的 SHA-256 摘要落库，默认 24 小时过期且可由结果所有者撤销；匿名读取只返回短期签名图片地址，不返回身体参数、任务输入或对象存储 key。分享本身不改变结果的私有保存状态。

## 接口

- `PUT /generation-jobs/:id/outputs/:outputId/selection`：确认唯一结果。
- `PUT /generation-jobs/:id/outputs/:outputId/saved`：云端保存。
- `DELETE /generation-jobs/:id/outputs/:outputId/saved`：取消云端保存。
- `DELETE /generation-jobs/:id/outputs/:outputId`：删除结果及未被引用的底层资产。
- `POST /generation-jobs/:id/outputs/:outputId/shares`：为已确认结果创建短期分享凭证。
- `POST /generation-shares/resolve`：通过请求体中的分享凭证匿名读取结果，避免将 token 放入 API URL/access log。
- `DELETE /generation-shares/:shareId`：结果所有者撤销分享凭证。

返回最新任务契约；删除重复调用成功但后续确认/保存返回 404。客户端未知响应可以刷新任务或安全重试同一操作。发布编辑从任务重新授权读取结果，不信任路由传入的图片 URL。

## 验收

真实 HTTP + PostgreSQL + Redis/local-svg 覆盖所有者/越权、重复写、候选切换并发、保存前确认、帖子引用与并发删除保护、删除无退款、资源清理任务、旧库升级默认值，以及分享创建、匿名读取、撤销和过期边界。小程序复用既有组件拆出结果操作区，覆盖提交锁、错误保留、刷新与离开后过期响应；微信工具/双端真机仍待验收。
