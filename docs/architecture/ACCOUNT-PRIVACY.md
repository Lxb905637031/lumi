# 账号隐私与数据生命周期

更新时间：2026-10-19。本文是 Lumi 账号导出和注销能力的实现边界，不替代上线前的正式隐私政策、法务审查或微信平台审核。

## 状态机

### 注销

`REQUESTED -> PROCESSING -> COMPLETED` 是系统清理主路径。用户在宽限期内可以执行 `REQUESTED -> CANCELLED`；清理故障进入 `FAILED`，系统把任务重新安排到下一次调度。`PROCESSING` 和 `COMPLETED` 不允许用户撤回。

每次状态变化写入 `account_deletion_events`，包含来源状态、目标状态、actor 类型和时间。用户行保留为 `DELETED`，微信标识替换为不可回收的 `deleted:<userId>`，用于阻止旧会话和旧身份重新登录，同时保留最小化审计事实。

### 数据导出

导出请求采用 `REQUESTED -> PROCESSING -> READY`，故障进入 `FAILED`。导出内容只允许请求所属用户读取，准备完成后按 `DATA_EXPORT_TTL_HOURS` 过期并清空 payload。重复请求在已有任务处理期间返回同一任务，避免并发生成大量副本。

导出包含用户档案、衣橱、试穿任务及结果元数据、帖子、评论、关注关系和通知元数据；不把私有对象原图复制进 JSON 导出，原图继续受媒体授权读取策略保护。

## 注销清理范围

注销事务先为私有对象和上传暂存对象登记 `object_cleanup`，再删除帖子、评论、互动、关注、通知、生成结果、生成任务、人物档案、衣橱、媒体、额度账本和会话。对象的物理删除由已有对象清理 worker 重试完成，数据库事务不依赖外部存储可用性。

注销处理和生成/发布创建都以用户行锁串行化；数据库唯一约束和状态条件防止重复处理。真实生产环境仍需配置定时调度、对象存储生命周期、备份保留策略、删除证明和客服/合规审批。
