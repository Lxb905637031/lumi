# 管理端权限矩阵验证

## 验证范围

- 守卫先由有效会话加载当前数据库角色，再执行角色和权限检查；因此变更角色后，后续请求立即按新角色授权。
- `MODERATOR` 可读取帖子、评论、图片、举报队列和运营总览，并可执行内容审核写入。
- `MODERATOR` 不可读取跨类型全局审计，也不可访问用户处罚、运行配置、公告、挑战和账号隐私管理。
- `ADMIN` 仍保留管理能力；普通 `USER` 访问管理端仍返回 403。
- 全局审计仅限管理员，避免审核员通过聚合查询读取用户处罚等超出审核职责的数据。

## 验证结果

- 完整 `pnpm check` 通过：格式、ESLint、类型检查、17 项 API 单测、30 项小程序单测和三端构建。
- 用户处罚及权限矩阵专项：45 次真实 loopback HTTP/PostgreSQL 请求通过，使用临时本地 fixture 账号。
- 帖子、评论、媒体审核专项分别通过 22、24、24 次真实 loopback HTTP/PostgreSQL 请求。
- 未连接外部服务、真实用户或付费能力；该结果不是生产环境授权验收。

## 保留项

矩阵是服务端静态策略，不含可配置 ACL、逐人授权界面、租户隔离、处罚审批流、生产人员目录或生产值守。
