- 参考图或文件：[全量设计评审稿](./DESIGN-REVIEW.md)、[海外产品原则迁移](./REFERENCE-MIGRATION.md)、[状态矩阵](./UX-STATE-MATRIX.md)

## 用户与核心任务

- 目标用户：希望复用已有衣物、减少搭配试错的成年用户。
- 使用场景：打开小程序浏览灵感，进入衣橱选择人物资料与单品，发起一次私有试穿。
- 唯一核心任务：建立私有人物资料 → 选择一件衣物 → 审阅额度和隐私 → 发起任务 → 确认结果 → 保存或审核发布。
- 成功标准：每一步只有一个主动作；失败、未知响应和拒绝授权都能恢复，不重复创建任务或泄露私有资料。

## 设计原则

1. 资产优先：人物、衣物和结果都保留版本、私有边界和明确状态。
2. 操作优先：页面使用连续画布、同质列表和上下文面板，不把每个区块套成卡片。
3. 克制强调：深绿只用于主操作和选中态，暖棕只用于少量提示；不用渐变、发光或营销型 Hero。
4. 真实边界：本地适配器、示例数据和设计示意必须显式标注，不能伪装成 AI 能力。

## 信息架构

- 一级页面：发现、衣橱、试穿、我的。
- 次级页面：人物档案、单品详情、生成记录、帖子详情、发布编辑、消息、关注与粉丝、账号与隐私。
- 入口与返回：分享/消息可直达帖子或任务；次级页始终提供返回首页或返回原任务；内容失效时保留解释和出口。
- 核心页面拓扑：发现使用媒体货架；衣橱使用同质单品网格；试穿使用上下文面板；生成和发布使用专注态连续画布。
- 浏览态导航：底部固定四项导航并预留 `safe-area-inset-bottom`。
- 专注态退出、保存与恢复：隐藏全局 TabBar，保留返回、状态和底部主操作；会话内恢复有效输入，不把照片签名或身体参数写入磁盘。

## Design Tokens

### Color

| 语义角色 | Token                    | 值        | 使用规则                       |
| -------- | ------------------------ | --------- | ------------------------------ |
| 页面背景 | `color-bg-page`          | `#F7F8F4` | 页面画布和安全区               |
| 容器背景 | `color-bg-surface`       | `#FFFFFF` | 列表、输入和图片信息区         |
| 主文字   | `color-text-primary`     | `#1F2722` | 标题、主要内容                 |
| 次文字   | `color-text-secondary`   | `#687368` | 说明、时间、分类               |
| 分割线   | `color-border`           | `#DEE4DB` | 低对比边界，不做装饰           |
| 主操作   | `color-action-primary`   | `#35483D` | 主按钮、选中态、关键链接       |
| 次强调   | `color-accent-warm`      | `#B27650` | 待处理、额度提示、少量品牌强调 |
| 错误     | `color-feedback-error`   | `#A64B3B` | 错误文字和边界                 |
| 成功     | `color-feedback-success` | `#3D7252` | 成功文字和状态                 |

### Typography

| 角色     | Token                | 字号/行高    | 字重 | 使用规则         |
| -------- | -------------------- | ------------ | ---- | ---------------- |
| 页面标题 | `type-page-title`    | 40rpx / 1.25 | 600  | 每页一个         |
| 分组标题 | `type-section-title` | 30rpx / 1.35 | 600  | 列表区段         |
| 正文     | `type-body`          | 27rpx / 1.55 | 400  | 说明和正文       |
| 辅助文字 | `type-caption`       | 22rpx / 1.45 | 400  | 时间、分类、状态 |

### Spacing / Radius / Elevation

- 间距刻度：8 / 12 / 16 / 20 / 24 / 32 / 40rpx。
- 小组件圆角：8rpx；输入和按钮：10rpx；媒体和大容器：14rpx。
- 阴影：默认不使用；浮层仅使用 `0 8rpx 32rpx rgba(31, 39, 34, .08)`。
- 触控目标：至少 88rpx；固定底部操作区包含安全区 padding。

## 小程序框架区

- 页面使用系统导航栏和微信右上角胶囊，不在业务页面重复绘制系统元素。
- 固定底部导航和 CTA 使用 `env(safe-area-inset-bottom)`，键盘顶起时不遮挡输入。
- 页面滚动由小程序页面负责；弹层若新增，必须只滚动自身内容并恢复背景位置。

## 组件系统

| 组件              | 变体                                    | 必需状态                     | 代码映射                                      |
| ----------------- | --------------------------------------- | ---------------------------- | --------------------------------------------- |
| Button            | primary / secondary / quiet / danger    | 默认、按下、禁用、加载、成功 | `components/ui/AppButton`                     |
| Input             | single / multiline / picker             | 默认、聚焦、错误、禁用、只读 | 业务 feature 表单                             |
| Surface           | plain / outlined / media                | 默认、按下、选中、只读       | feature SCSS 的 `surface` 规则                |
| ResourceStatus    | loading / empty / error                 | 首次空、筛选空、可恢复错误   | `components/ui/ResourceStatus`                |
| BottomNavigation  | discovery / wardrobe / try-on / profile | 默认、选中、按下             | `features/home/components/BottomNavigation`   |
| PrivateMediaImage | private / public                        | 加载、失败、重试、过期       | `features/media/components/PrivateMediaImage` |

## 禁止项

- 不复制 Whering、Pinterest、Indyx 的 Logo、字标、品牌摄影、招牌配色、专有文案和整屏组合。
- 不使用渐变、发光圆球、营销 Hero、伪造仪表盘或卡片套卡片承载核心任务。
- 不把固定示例数据、local-svg、Unsplash 图片或本地预览描述为生产 AI 能力。
- 不用浏览器 DOM、`window`、`document` 或浏览器存储 API 实现微信页面。

## 验收标准

- 所有一级页面使用同一套 Token 和导航，主动作可在首屏识别。
- 列表、图片、表单和写操作覆盖 loading、empty、error、permission denied、submitting、success、stale response。
- Taro weapp 构建、TypeScript、单测通过；微信开发者工具和 iOS/Android 真机完成后才标记平台交付。
