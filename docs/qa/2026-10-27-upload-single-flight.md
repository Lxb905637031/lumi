# 小程序同文件上传并发合并

## 场景与处理

- 同一登录会话、同一临时文件路径被并发提交时，共用同一客户端上传任务，避免重复直传、并发完成请求导致其中一次界面误报失败。
- 上传和服务端处理进度广播到该任务的所有调用方。
- 任务失败后只释放并发锁；保留上传幂等键、预留资产 ID 和已成功直传状态，后续重试可从失败环节恢复。
- 服务端 API、签名策略、上传大小限制和租约未修改；没有实现或宣称分片续传。

## 边界

并发合并只在当前小程序进程内、按当前会话 epoch 和临时文件路径生效。应用进程退出后状态不持久化；跨设备、断点续传、分片校验和生产对象存储高可用不在本项范围内。
