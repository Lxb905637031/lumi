## 状态口径与实际进度

- ✅：仅表示本行明确限定的能力已实现并有验证证据。标注 API 的行只验收接口，不代表微信页面或生产环境通过。
- 🟡：已有部分实现，或代码已经写入但尚未完成该项全部验收；不能算已完成。
- ⬜：尚未实现，或尚无可验收交付物。上线环境/资质等需要真实资源的事项也明确保留为未完成。
- 免费约束：不购买服务、不使用真实付费模型/支付，不把本地 fixture、数据库 base64、local-svg 冒充生产能力。
