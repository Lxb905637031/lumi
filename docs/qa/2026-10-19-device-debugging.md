# 真机接口连接修复记录

## 已确认的问题与改动

- 原 weapp 产物将 API 编译为 `http://127.0.0.1:4300/api/v1`。手机上的此地址指向手机本身。
- API 现有实现已监听 `0.0.0.0:4300`，Mac 防火墙已允许 Node 入站，无需修改防火墙规则。
- 新增 `build:device` 命令，自动选择唯一物理局域网 IPv4，排除常见虚拟/VPN 网卡；可用 `TARO_DEVICE_HOST` 或 `TARO_APP_API_BASE_URL` 指定地址。
- 本机未纳入 Git 的 `apps/miniapp/.env.local` 固定 API 为 `http://192.168.1.10:4300/api/v1`，避免普通构建恢复 loopback 地址。
- 图片上传/读取之前使用 loopback S3 地址，Compose 也只绑定本机。可选的 `docker-compose.device.yml` 增加指定局域网 IP 的 S3 端口，并保留原 loopback 端口及数据卷。
- 当前 API 通过 `S3_ENDPOINT=http://192.168.1.10:59000 pnpm --filter @lumi/api start` 启动。覆盖值仅作用于该进程；后续重启需沿用此命令，或按运行手册恢复本机模式。
