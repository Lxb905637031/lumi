# 小程序质量闸门

在阶段 7 和阶段 8 使用本清单。先记录证据，再决定是否通过。

## 1. 产品与 UX

- [ ] 每个页面都有一句目标和一个主要动作。
- [ ] 页面先按连续画布、同质列表、媒体货架、自包含卡片或上下文面板选择拓扑，没有默认卡片化。
- [ ] 搜索、扫码、分享、消息、二维码直达等入口都能独立进入正确上下文。
- [ ] 页面没有死路；返回、关闭、回首页语义明确。
- [ ] 核心流程覆盖正常、失败、中断、恢复、成功和再次进入。
- [ ] 状态矩阵覆盖首次加载、局部加载、首次空、筛选空、错误、超时、弱网、离线、会话失效、未授权、拒绝授权、内容失效和版本变化。
- [ ] 表单失败时保留有效输入，错误提示靠近问题字段。
- [ ] 提交、支付、收藏等操作防重复；未知结果可以查询、重试或安全退出。
- [ ] 浏览态保留稳定导航；专注态隐藏 TabBar，只保留必要进度、退出和主操作。
- [ ] 返回或再次进入时恢复任务进度、滚动位置、筛选和有效输入。

## 2. 小程序平台

- [ ] 状态栏、右上角胶囊、导航栏和点击安全区未遮挡核心内容。
- [ ] 刘海、动态安全区、底部安全区、横屏和键盘顶起不会破坏布局。
- [ ] 分享或扫码直接进入次级页面时有返回首页或恢复主流程的路径。
- [ ] 页面栈、TabBar、返回和关闭行为符合用户预期。
- [ ] 权限只在需要时申请，申请前说明用途，拒绝后仍有退路。
- [ ] 冷启动、分包加载、图片失败、弱网和恢复前台有明确体验。
- [ ] 原生能力、地图、相机、支付、授权和输入键盘在真实微信运行时验证。
- [ ] 重要页面在常见屏宽、iOS 和 Android 上无裁切、抖动或层级错误。

## 3. UI Craft

- [ ] 灰度下仍能清楚识别主次和操作顺序。
- [ ] 间距、字阶、灰阶、圆角和阴影全部来自既定 Token。
- [ ] 单个界面字号不超过 4–6 档，字重不超过 3 档。
- [ ] 正文对比度至少 4.5:1；大字号至少 3:1。
- [ ] 状态不只靠颜色表达，错误和成功有文字或图标说明。
- [ ] 触控目标达到至少 44×44pt 或 48×48dp，并在真机确认。
- [ ] 卡片内边距、列表节奏、对齐和圆角关系一致。
- [ ] 正式素材尺寸、裁切、色调和密度匹配使用位置。
- [ ] 默认、按下、选中、禁用、加载、错误、成功、只读和长内容状态完整。

## 4. 动效与知识卡动画

- [ ] 动画有明确的信息或反馈职责；静态图足够时没有强行制作语义动画。
- [ ] 静态卡独立可用，包含一句话结论、有意义的海报、时长/幕数和静态阅读入口。
- [ ] 语义动画由用户触发、默认播放一次；同屏没有多张知识卡同时自动播放。
- [ ] 海报、加载、播放、暂停、结束、错误、精简、关闭和再次进入状态完整。
- [ ] 多幕内容可暂停、继续、跳幕、重播和退出；结束后停在可读终态。
- [ ] 信息不只存在于声音、颜色、震动、纸屑、Toast 或瞬时运动中。
- [ ] 精简和关闭模式保留同样的知识与操作；弱网或资源失败退回静态图解。
- [ ] 动画由 `motion_state` 和 `beat_id` 驱动，不依赖散落定时器；关键帧可冻结和测试。
- [ ] 没有逐帧 `setData`；Canvas rAF、CSS 循环、Video 和 Lottie 在隐藏/卸载时正确暂停、取消或销毁。
- [ ] 页面隐藏、离屏和卸载会暂停并释放非必要资源；返回后不会静默续播。
- [ ] 完整、精简、关闭、弱网和错误均有证据，并在 iOS/Android 真机检查资源、首播等待、内存和流畅度。
- [ ] 包体、首播、帧率和内存阈值来自项目约束或可复现实测；没有把经验值冒充平台通用上限。

## 5. 视觉对照

- [ ] 每项外部参考都记录了具体任务时刻、可迁移原则、小程序改写和禁止复制项。
- [ ] 去品牌后方案仍服务本产品；未复制来源的 Logo、吉祥物、招牌配色、品牌文案、独有奖励系统或整屏组合。
- [ ] 参考稿与实现截图使用相同视口、内容、滚动位置和状态。
- [ ] 两张图放入同一次比较，而不是凭记忆评审。
- [ ] 检查字体、字重、行高、间距、圆角、边框、阴影、图片裁切和安全区。
- [ ] 修复后重新截图比较，并记录尚未关闭的差异及理由。
- [ ] 动态时间、头像、随机数据和动画已固定或从视觉基线中排除。

## 6. 发布门

- [ ] 微信开发者工具无阻断级控制台、编译或运行错误。
- [ ] 核心流程在 iOS 与 Android 真机完成。
- [ ] 无障碍、触控、弱网、权限拒绝和恢复路径已验证。
- [ ] `DESIGN.md`、状态矩阵、`MOTION-SPEC.md`、组件实现和当前截图/录屏保持一致。
- [ ] P0 全部关闭；P1 已关闭或由用户明确接受；P2 有后续计划。
