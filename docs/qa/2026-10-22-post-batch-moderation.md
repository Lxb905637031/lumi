# B02 帖子批量审核验收

## 范围

- 管理后台帖子队列支持选择当前页记录，批量通过、拒绝；已通过队列可批量下架。
- `PATCH /api/v1/admin/moderation/posts/batch/status` 最多处理 50 条，拒绝重复 ID、无效状态和空数组。
- 同一数据库事务内按 ID 顺序锁定所有帖子；遇到不存在、已删除或不允许的旧状态时整批回滚。
- 每条实际状态变更都写审核动作、通知作者，并按通过/拒绝状态同步媒体可见性。
- 已处于目标状态的记录幂等跳过并计入 `skippedCount`，不会重复写审计或通知。

## 验收命令

```sh
LUMI_API_URL=http://127.0.0.1:14330/api/v1 pnpm --filter @lumi/api test:post-moderation
```

## 验收结果

已通过 22 次真实 loopback HTTP/PostgreSQL 请求，覆盖管理员权限、普通用户拒绝、重复 ID DTO 校验、批量成功、重复请求幂等跳过、混合有效/过期状态整批回滚、公开 Feed 隔离、逐条审计与作者通知。

测试只创建带唯一 runId 的本地临时账号/帖子并在 `finally` 清理，不访问外部服务。该证据不代表微信后台页面真机验收或生产部署。
