# B08 审计检索验收

## 范围

- `GET /api/v1/admin/audit` 合并帖子、评论、媒体、用户状态变更记录。
- 仅管理员和审核员可访问；支持类型、操作者 ID、目标 ID 筛选及游标分页。
- 用户角色变化一并显示在状态变更字段中；响应不返回媒体对象键、图片预览数据或账号私密字段。
- 管理后台提供筛选、错误/空状态、刷新和加载更多。

## 验收命令

```sh
LUMI_API_URL=http://127.0.0.1:4358/api/v1 pnpm --filter @lumi/api test:audit-search
```

## 验收结果

已通过 12 次真实本地 HTTP/PostgreSQL 请求。测试使用临时本地账号及数据库记录，不访问外部服务。

覆盖：

- 管理员/普通用户 RBAC、非法类型、非法页大小和坏游标拒绝；
- 帖子、评论、媒体、用户四类审计统一返回，游标跨页无重复；
- 类型、操作者 ID、目标 ID 筛选；
- 用户角色变更的前后状态；
- 响应严格限制为 `id`、`type`、`targetId`、`actorId`、`fromStatus`、`toStatus`、`reason`、`createdAt` 八个公开字段，不包含对象键、预览数据和账号私密字段；集成测试锁定字段集合。

## 未覆盖

- 报表导出、趋势聚合和产品埋点指标。
- 生产数据库、生产权限账号、运行告警及值守验收。
