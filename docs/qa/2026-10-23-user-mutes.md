# 用户禁言闭环验证

日期：2026-10-23

## 实现范围

- 新增 `user_mutes` 持久化模型和迁移；禁言独立于账号封禁，保留原因、操作者、开始/结束时间、撤销时间及撤销人。
- 管理端管理员可创建限时或永久禁言、解除禁言，并查询禁言历史。用户列表显式返回当前有效禁言摘要。
- 禁言和解除禁言均锁定用户行、校验 `expectedUpdatedAt` 并推进用户版本时间；旧页面提交将收到冲突。
- 发帖和评论在写入事务内锁定用户行后检查禁言，与处罚写事务串行，防止刚禁言仍成功写入。到期禁言按数据库时间条件失效，不依赖定时任务。

## 验证结果

- `pnpm db:deploy`：成功应用 `20261023070000_user_mutes` 到本机 PostgreSQL。
- `pnpm --filter @lumi/api test:user-moderation`：31 次真实 loopback HTTP 请求通过，包含非管理员拒绝、限时禁言、发帖/评论拒绝、到期后恢复、撤销记录和旧版本冲突。
- 全仓格式、lint、类型检查、单测和三个应用构建：见提交前本轮 `pnpm check` 结果。

测试只使用本机 API/PostgreSQL 与带唯一 run ID 的临时用户；无外部服务、真实用户或付费能力。生产部署、后台人工验收和微信真机测试仍未完成。
