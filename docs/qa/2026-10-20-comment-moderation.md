# 2026-10-20 评论审核闭环验证

## 范围

评论审核后台状态筛选、服务端游标分页、审核动作、事务审计、作者通知及管理后台浏览器操作。仅在本机 FREE_MODE、PostgreSQL 和真实本地 HTTP API 验证；不代表微信真机或生产值守验收。

| 检查         | 结果 | 证据                                                                                      |

专项覆盖 moderator RBAC、非法状态和 limit 拒绝、按状态筛选、游标分页无重复、待审评论审核通过后离开待审队列、已通过评论下架后进入 REMOVED 队列、审核动作操作者/原因审计及作者通知。

## 后台浏览器

通过本地 Vite（4401）和本地 Nest API（4358）使用临时 moderator 凭据登录。真实页面显示数据库评论；切换“已通过”后出现测试评论，点击“下架”并填写原因，评论从当前队列移除；切换“已下架”后可见相同记录。页面请求均走真实 API，管理员视角浏览器控制台错误为 0。

为了测试完整管理员工作台，将临时本地账号提升为 ADMIN；浏览器操作后删除该唯一测试用户和帖子，关联评论、审计、通知和凭证由数据库级联清理。没有触碰其他本地数据。
