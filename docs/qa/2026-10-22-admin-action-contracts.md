# 后台审核动作响应契约验证

日期：2026-10-22

## 变更

- 评论审核、媒体审核和用户处罚的动作历史响应从查询行对象展开改为显式字段映射。
- HTTP 集成测试断言每种动作记录的响应键集合，防止 ORM 字段意外进入 API 契约。

## 验证

在独立当前版本 API `127.0.0.1:14330` 上，使用本地 PostgreSQL 和隔离测试账号运行：

- 评论审核：19 次真实 HTTP，通过 RBAC、状态迁移、审计字段、通知和游标分页。
- 媒体审核：19 次真实 HTTP，通过权限、图片所有权、并发版本冲突、审核历史及生成输入阻断。
- 用户处罚：21 次真实 HTTP，通过权限、封禁会话撤销、乐观并发、解封、角色审计和自我保护。

另运行私有签名上传专项 34 次真实 HTTP，覆盖签名策略、对象实际上传/读取、并发完成、损坏内容拒绝、失效租约恢复、删除竞争和物理清理；试穿客户端工作流 27 次真实 HTTP，通过实际 S3 图片与 PostgreSQL/Redis 状态校验。

上述均为本地开发环境验证，不代表微信真机或生产验收；试穿生成使用 `local-svg` 开发适配器，不是真实 AI 模型。
