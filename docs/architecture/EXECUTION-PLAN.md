## 每个阶段门

- 先记录边界和验收条件，再写代码；持久化修改必须有可审查迁移，禁止重置用户数据库。
- 写入有权限、并发/幂等和恢复策略；跨应用变化同步契约和客户端。
- 自动化正反例、实际 HTTP 与相应 UI/平台测试；本地与生产结论严格分开。
- 更新交付矩阵、验证记录、未关闭风险；运行 check，提交可回滚 commit，再无冲突推送。
- 普通工程失败自行修复。只有费用、真实凭据、外部不可逆操作、平台审核或必须由用户确认的产品/法律决策才请求确认。
