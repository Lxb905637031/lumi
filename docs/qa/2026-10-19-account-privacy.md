# 账号隐私联调记录

命令：`pnpm --filter @lumi/api test:account-privacy`

本次使用本地 NestJS HTTP、PostgreSQL、Redis 和对象清理依赖，创建带唯一 runId 的开发账号，测试结束删除 fixture；没有调用付费模型或生产资源。

通过 16 次带状态断言的 HTTP 请求：

- 导出必须携带显式确认，异步任务进入 READY 后只允许所属用户下载。
- 重复导出申请在已有任务处理期间复用同一请求，跨用户读取返回 404。
- 注销申请可以撤回；撤回后再次申请生成同一账号的下一次状态流转。
- 管理员处理到期请求后，用户变为 `DELETED`，微信标识被替换，会话失效。
- 注销完成后导出 payload 过期清空，注销事件记录保留并包含完整状态流转。

这份记录只证明本机链路和数据库行为；微信开发者工具、真机、生产对象存储、正式隐私政策和平台审核仍是上线门槛。
