# 2026-10-19 私有图片链路实测

## 已通过

- `pnpm check`：格式/Lint/全 workspace 类型、17 项 API 单测、Nest/Vite/Taro weapp 构建。
- `pnpm test:migrations`：空库/重复 deploy、旧基线纳管与增量升级、结构漂移拒绝、用户/档案/原有 local 媒体哨兵保留。public 增量迁移未删除原数据。
- 真实本机 Docker SeaweedFS 4.48（固定 digest，Apache-2.0）、PostgreSQL、Redis 和 Nest HTTP，不是存储 mock。
- 主业务回归 101 次带状态断言 API 请求、2 次 CORS 检查，人物/衣物/发帖使用 signed-post；生成仍为 local-svg。
- 存储专项：34 次计数 API 调用，另 3 次并发完成、2 次完成/删除竞争，以及实际 S3 POST/GET/HEAD 与清理查询。
- 固定 key/大小策略拒绝篡改、匿名访问 403、他人读取/完成 404、PENDING 不可关联档案、同请求去重、READY 重复完成、坏图拒绝、过期拒绝、处理中断恢复。
- 下载真实字节核对 WebP、尺寸、SHA256、EXIF/ICC 清理，篡改签名到期参数被拒绝。
- 自有待审可预览，匿名不可见；通过后公开上下文可签发短时 URL；删除后停止签发。实际 worker 验证物理删除、孤儿回收与活跃对象保护；单测模拟删除失败并保留退避任务。

## 工程问题与处置

- MinIO 旧 tag/latest 无法拉取，官方旧二进制返回 410；采用 S3 协议兼容的 SeaweedFS 固定版本，保留旧 MinIO 卷。
- 首轮合法上传出现 500，实查为默认 volume 分配耗尽本地容量；修正容量配置后完整回归通过，未放宽签名或改公开桶。
- 一次服务重启打断 fixture 清理，已核对并清理该次两个唯一测试账号及自有对象；现清理失败仍移除数据库 fixture、保留持久对象重试且退出失败。
- 旧 PNG fixture 只通过文件头校验而不能完整解码，现用真实编码图片，不再把文件头当图片有效性依据。
