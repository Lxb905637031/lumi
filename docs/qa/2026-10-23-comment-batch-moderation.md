# B03 评论批量审核验收

## 范围

- 管理后台评论队列支持选择当前页记录，批量通过、拒绝；已通过队列可批量下架。
- `PATCH /api/v1/admin/moderation/comments/batch/status` 最多处理 50 条，拒绝重复 ID、无效状态和空数组。
- 同一数据库事务内按 ID 顺序锁定所有评论；遇到不存在或不允许的旧状态时整批回滚。
- 每条实际状态变更都写评论审核动作、作者通知；通过已审核帖子中的评论时保留互动通知逻辑。
- 已处于目标状态的记录幂等跳过并计入 `skippedCount`，不会重复写审计或通知。

## 验收命令

```sh
LUMI_API_URL=http://127.0.0.1:14330/api/v1 pnpm --filter @lumi/api test:comment-moderation
```

## 验收结果

已通过 24 次真实 loopback HTTP/PostgreSQL 请求，覆盖审核角色 RBAC、普通用户拒绝、重复 ID DTO 校验、批量成功、重复请求幂等跳过、混合有效/过期状态整批回滚、状态队列迁移、审计游标和通知计数。

测试只创建带唯一 runId 的本地临时账号/帖子/评论并在 `finally` 清理，不访问外部服务。该证据不代表微信后台页面真机验收或生产部署。
