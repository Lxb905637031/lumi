## 小程序验收项

试穿资料与额度（本轮）：初始由“选择试穿资料”触发登录/加载，人物和衣物必须显式选择；加载失败保留已选内容并可重载，更多资料可分页加载。额度为 0 时明确阻止新建/人工重试，仍可查状态/取消。提交前确认人物版本、单品和消耗规则；提交/取消防重，轮询不锁取消。未知提交结果锁住输入并保留幂等键，重试原请求不会新建；取消或终态后才能改输入。离开清定时器、丢弃过期响应；同会话返回恢复原请求/任务，不恢复别的用户资料。原始素材已删除或档案不可用时服务端拒绝，不默默换第一条。原生 Picker、权限拒绝、真实弱网和双端设备结果仍待微信验收。

图片协议升级（沿用现有布局和视觉组件）：选图后校验大小，预留固定 key 的签名直传；上传结束只表示对象到达 staging，完成接口返回 READY 才能关联档案/衣物/帖子。网络失败保留本次文件路径与上传请求标识，原租约内重试不创建重复资产；显示错误时保留其它表单输入。不持久化签名 URL/表单凭据；断点续传、可视进度和微信真机验收仍未关闭。此轮只修改上传服务，不新增视觉样式；ui-craft 技能当前不可用，因此不开展界面重设计。

后台会话验收：并行请求遇到授权过期时只轮换一次 refresh token；网络或 5xx 失败保留会话供重试；刷新凭据失效或退出后回到登录表单，不保留可操作工作台。该流程沿用现有 Lumi 组件样式，不新增视觉方向。

- 页面不使用 DOM API；图片和文件操作使用 Taro API。
- 权限拒绝后仍可浏览公开 Feed，并能从业务入口重新授权。
- 弹层只滚动自身内容，关闭后恢复背景滚动位置。
- 固定底部操作区包含安全区 padding，真机检查刘海和键盘顶起。
- 生成、发布和支付（后续开启）都使用幂等提交。
