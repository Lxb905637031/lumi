## 小程序验收项

后台会话验收：并行请求遇到授权过期时只轮换一次 refresh token；网络或 5xx 失败保留会话供重试；刷新凭据失效或退出后回到登录表单，不保留可操作工作台。该流程沿用现有 Lumi 组件样式，不新增视觉方向。

- 页面不使用 DOM API；图片和文件操作使用 Taro API。
- 权限拒绝后仍可浏览公开 Feed，并能从业务入口重新授权。
- 弹层只滚动自身内容，关闭后恢复背景滚动位置。
- 固定底部操作区包含安全区 padding，真机检查刘海和键盘顶起。
- 生成、发布和支付（后续开启）都使用幂等提交。
